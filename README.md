# BRS AI Recruiter

A free-first recruitment management MVP for BRS Career Dream Job's.

## Phase 1 scope
- Candidate registration: Fresher and Experienced
- Candidate profile editing and resume versioning
- Admin dashboard and recruiter workflows
- Company and vacancy management
- Rule-based matching and pending candidate queue
- Document verification tracking
- Interview scheduling and application history
- Consultancy fee agreements and payment ledger reporting
- Dashboard notifications

## Planned stack
- Next.js + TypeScript
- Supabase Auth + PostgreSQL + Realtime
- Private Google Drive folder for files (OAuth integration is pending)
- A commercially permitted free-tier host, subject to current plan terms

## Important
- No production candidate data until authentication, RLS, storage access, and backup checks pass.
- No WhatsApp automation, AI API, calling, or live payment processing in Phase 1.
- Never store real passwords in code or repository secrets.
- Never publish resumes or identity documents through public URLs.
